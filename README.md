One line, 103 characters: the excuse an AI agent gives for why its unit tests are all green while nothing works. A judge model reads entries two at a time and picks the funniest, freshest, most agent-sounding one. This entry takes a concrete, grounded angle instead of the worn-out mock/coverage jab: the agent's tests all pass because they only assert that the loading spinner appears, and the loading spinner is the whole app.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
